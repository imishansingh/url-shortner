# URL Shortener + Analytics Dashboard

A full-stack web application for shortening URLs and tracking click analytics.

## Tech Stack

- **Backend**: Python + FastAPI
- **Database**: PostgreSQL
- **Cache**: Redis
- **Frontend**: React
- **DevOps**: Docker + GitHub Actions

## Project Structure

```
urlshortener/
├── backend/        # Python FastAPI application
│   └── app/        # Application source code
├── frontend/       # React application
├── ROADMAP.md      # Learning roadmap and progress
└── README.md       # This file
```

## Features

- Shorten any URL to a compact link
- Redirect short links to the original URL
- Track click count per link
- View analytics dashboard
- User accounts with authentication
